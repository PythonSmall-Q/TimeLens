TimeLens VS Code Extension

追踪 VS Code 编码会话，并将本地分析数据同步到 TimeLens 桌面端，按项目与语言维度洞察你的开发时间。

Visual Studio Marketplace 浏览源码

快速开始

  1. 获取 API 密钥：在 TimeLens 桌面端「设置 → 本地 API / Extension Bridge」复制 Extension Bridge Key。
  2. 配置扩展：打开 VS Code，找到 TimeLens 侧边栏，点击「⚙️ 配置 API 密钥」按钮，或使用命令 TimeLens: Set Extension Bridge Key。
  3. 开始追踪：VS Code 会话将自动同步到 TimeLens。

⚠️ 注意：若未配置 API 密钥，数据会暂存本地，但无法同步到桌面端。

功能特性

  • 按项目和语言追踪会话时长
  • 本地优先上报到 http://127.0.0.1:49152
  • 桌面端临时不可用时使用内存队列重试
  • VS Code 侧边栏实时显示同步状态
  • 命令支持：
    • TimeLens: Enable Tracking
    • TimeLens: Disable Tracking
    • TimeLens: Show Tracking Status
    • TimeLens: Set/Update Extension Bridge Key

环境要求

  • TimeLens 桌面端正在本地运行
  • 本地 API 服务器已启用（默认端口 49152）
  • 在 TimeLens 设置中获取 Extension Bridge Key

扩展设置

设置项说明
timelens.enabled启用/禁用追踪
timelens.apiBaseUrl本地 API URL（默认 http://127.0.0.1:49152）
timelens.bridgeKey来自 TimeLens 设置的 extension bridge key（同步必需）
timelens.trackingLevel记录详细级别：basic / standard / detailed
timelens.flushIntervalSeconds队列刷新间隔（默认 30 秒）
timelens.idleThresholdSeconds空闲切分阈值（默认 120 秒）

常见问题

"Extension bridge key authentication failed"

  • 检查设置中的 API 密钥是否正确
  • 确保 TimeLens 桌面端正在运行
  • 重启 VS Code

"未连接到 TimeLens 桌面端"

  • 启动 TimeLens 桌面端
  • 检查设置中是否启用了 Local API
  • 确认 timelens.apiBaseUrl 与实际情况一致

数据未同步

  • 确认已配置 API 密钥（见快速开始）
  • 检查侧边栏中追踪是否已启用
  • 查看 VS Code 输出面板中的错误信息

构建与打包

npm install
npm run build

# 打包为 VSIX
npm run package

# 或在仓库根目录执行
npm run ext:package

隐私说明

  • 不收集源代码内容
  • 不在追踪负载中收集文件路径
  • 数据仅发送至本地 TimeLens API
  • API 密钥仅存储在 VS Code 本地设置中
