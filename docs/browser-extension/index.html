Browser Companion

TimeLens 浏览器扩展

Edge / Chrome 浏览器伴侣。记录网页访问时长，按域名聚合统计，并与桌面端 TimeLens 数据合并展示。

Edge 商店安装 查看源码 返回文档中心

版本 v1.1.0 · 支持 Chromium 内核浏览器（Edge、Chrome）

概览

它如何工作

浏览器扩展通过 Service Worker 监听浏览器活动，仅在窗口聚焦且用户活跃时记录当前标签页会话，并将数据安全地同步到本地 TimeLens API。

标签级会话追踪

只在浏览器窗口获得焦点且用户未空闲（chrome.idle）时计时。切换标签、窗口失焦或进入空闲状态会立即结束当前会话并同步。

域名聚合

桌面端 Browser Usage 页面按域名展示总时长、趋势和限额，与本地应用屏幕时间并列呈现。

本地优先

所有数据仅发送到本机 127.0.0.1 上的 TimeLens API。不上传云端，不收集页面内容。

功能

扩展功能一览

网页会话追踪

按标签页记录活跃浏览时间，窗口失焦或用户空闲时自动暂停，恢复后继续计时。

忽略域名

在 TimeLens 桌面端 Browser Usage 页面配置忽略的域名，例如 localhost、企业内部 SSO 页面，避免干扰统计。

域名限额

为特定网站设置每日使用限额，超额时桌面端会通过原生通知提醒你。

扩展桥接密钥

通过 TimeLens 桌面端 Settings 生成的桥接密钥验证扩展身份，防止未授权工具访问本地 API。

灵活的连接设置

手动指定 API 端口、选择缓存模式（时长 / 下次启动前）、自定义缓存时长。手动端口失败时自动扫描备用端口范围。

实时弹窗状态

点击浏览器工具栏图标即可查看桌面连接状态、今日总览和最近网页会话列表。

安装

三步开始使用

1

安装扩展

从 Microsoft Edge 加载项 安装，或从源码运行 npm run build:chrome 后手动加载。

2

启动桌面端

确保 TimeLens 桌面应用正在运行，并且 Settings 中启用了 Local API / Extension Bridge。

3

配置桥接密钥

在桌面端 Settings 复制 Extension Bridge Key，粘贴到扩展弹窗的桥接密钥输入框中并保存。

配置

连接设置说明

v1.1.0 起，扩展支持更精细的本地 API 发现策略，解决 Windows 排除端口或安全软件导致默认端口不可用的问题。

设置项说明
API Port 手动指定 TimeLens 本地 API 端口。默认 49152；留空或填 0 时直接扫描备用端口范围。
Cache mode Duration：按秒缓存已发现的 API 地址；Until next startup：浏览器本次运行期间一直使用缓存地址，重启后重新发现。
Cache duration 在 Duration 模式下缓存的秒数，默认 60 秒，最大 3600 秒。
自动回退扫描 当手动端口连续失败 5 次后，扩展会暂时忽略该端口并自动扫描 49152–50151 备用端口范围，5 分钟后恢复手动端口尝试。

获取桥接密钥

打开 TimeLens 桌面端 → Settings → Local API / Extension Bridge → 点击复制 Extension Bridge Key。该密钥用于扩展向本地 API 签名请求，确保只有授权扩展能写入数据。

故障排查

常见问题

扩展一直显示 “Checking” 或连接失败

  1. 确认 TimeLens 桌面端正在运行。
  2. 在桌面端 Settings 检查 Local API 是否已启用。
  3. 打开扩展弹窗，确认已保存正确的 Extension Bridge Key。
  4. 尝试将 API Port 改为 0 让扩展自动扫描备用端口。
  5. 检查 Windows 防火墙或杀毒软件是否拦截了 127.0.0.1 环回地址。

桥接密钥认证失败

  1. 重新从桌面端 Settings 复制完整的 Extension Bridge Key。
  2. 在扩展弹窗中粘贴并保存，然后刷新弹窗。
  3. 如果旋转过密钥，所有扩展都需要重新配置。

网页数据未显示在桌面端

  1. 在扩展弹窗中点击 Refresh 查看最新状态。
  2. 确认访问的域名不在 TimeLens 桌面端的“忽略域名”列表中。
  3. 检查浏览器 DevTools 中是否有 Service Worker 报错。
  4. 重新启动浏览器或重新安装扩展。

端口 49152 被占用

TimeLens v2.0.2 桌面端会在 49152 被占用时自动扫描 49152–50151 并绑定到第一个可用端口。扩展侧也支持自动回退扫描，因此无需手动查找实际端口。
